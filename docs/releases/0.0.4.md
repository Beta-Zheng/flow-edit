# Flow Edit 0.0.4

## 更新

- 选区工具栏改为纯图标，统一线宽、下拉箭头和悬停提示，保留当前块类型图标与无障碍名称。
- 工具栏、块菜单与子菜单统一柔和圆角、轻阴影、浅灰悬停和淡蓝选中态。
- 颜色与对齐面板共用布局和选项，统一内缩边距与选中勾，保留返回和缩进操作。
- 优化深色模式、键盘焦点和触屏按钮尺寸；正文对齐保持不变。
- README 更新 2 倍像素、无鼠标指针的截图，补充颜色与对齐展示。

## 安装与升级

下载本版本的 `main.js`、`manifest.json` 和 `styles.css`，放入 `<笔记库配置目录>/plugins/flow-edit/`。升级时先停用插件，覆盖三个文件并保留 `data.json`，再启用插件。
