# Flow Edit 0.0.2

## 更新

- 修复块操作按钮与 Markdown 标题折叠箭头过近的问题，按折叠控件实际边界保留至少 12px 点击间隔。
- 边距不足时使用紧凑按钮，仍放不下时隐藏按钮，可通过右键菜单操作；正文对齐保持不变。
- README 更新四张无鼠标指针的高清功能截图。

## 安装与升级

下载本版本的 `main.js`、`manifest.json` 和 `styles.css`，放入 `<笔记库配置目录>/plugins/flow-edit/`。升级时先停用插件，覆盖三个文件并保留 `data.json`，再启用插件。

## 验证与兼容性

- 自动测试、格式检查、官方 Obsidian ESLint、元数据与发布产物检查通过；新增七项按钮间距回归场景。
- 已在 Obsidian 1.15.0 桌面实时预览中验证标题折叠、展开与块菜单独立点击。
- 最低声明版本仍为 Obsidian 1.5.0；最低版本设备与移动端界面尚未完成验收。
- 已安装 0.1.x–0.3.x 本地开发版的用户需手动覆盖安装，并保留 `data.json`。
