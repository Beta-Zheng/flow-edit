# Flow Edit 0.3.4

First public source release of Flow Edit: Markdown editing with slash insertion, block actions, callout type selection and a selection toolbar.

## Included

- Insert common Markdown blocks with `/` search.
- Convert, duplicate, move and format blocks; keep editing controls outside the content column.
- Apply inline formatting after selection completes, with keyboard navigation.
- Change callout types while preserving their title, fold marker, metadata and body.
- Keep document appearance independent: use the current Obsidian theme, optionally Lumen Docs.
- Build from organized sources with official Obsidian linting, automated tests and release validation.

## Install

Download `main.js`, `manifest.json` and `styles.css` from this release. Place them together in `<vault-config-dir>/plugins/flow-edit/` and enable Flow Edit in Community plugins. Preserve your existing `data.json` when upgrading. Node.js is required only for development, not installation.

## Compatibility and migration

- Minimum declared Obsidian API version: 1.5.0. The minimum-version device test has not been completed.
- The runtime does not import Node.js/Electron modules. Mobile UI acceptance has not been completed; desktop live preview is the primary verified workflow from earlier development.
- Optional comment integrations now use the public Workspace provider event described in `docs/comment-bridge.md`. Older companion plugins that only expose a private command need an update.
- This GitHub release is not an approval or listing in the Obsidian Community directory.
