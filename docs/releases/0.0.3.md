# Flow Edit 0.0.3

## 更新

- 新增图片布局：多图同行、1–4 列均分，拖拽图片间的边缘调整宽度；支持键盘微调、Esc 取消及恢复普通图片。
- 图片布局兼容实时预览和阅读视图，窄窗格自动换行，不修改原图。
- 完成插件审查整改：严格 TypeScript 类型检查、ESM 源码导入、公开编辑器接口和 CSS 兼容性修正。
- 发布流程为三个安装文件生成并验证 GitHub 来源证明。
- README 增加无鼠标指针的高清图片布局截图和使用说明。

## 安装与升级

下载本版本的 `main.js`、`manifest.json` 和 `styles.css`，放入 `<笔记库配置目录>/plugins/flow-edit/`。升级时先停用插件，覆盖三个文件并保留 `data.json`，再启用插件。

## 验证与兼容性

- 75 项自动测试通过，1 项可选主题检查跳过；严格类型、lint、格式和发布产物检查通过。
- 图片布局已在 Obsidian 1.15.0 桌面实时预览和阅读视图中验收；本次迁移另经浏览器回归验证。
- 最低声明版本仍为 Obsidian 1.5.0；最低版本设备及移动端界面尚未完成验收。
- 图片组使用原生 Callout 保存；停用插件后仍可查看，旧版插件不能调整图片组宽度。
